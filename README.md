# ⚡ SVG Path Animator & Code Exporter

An interactive, client-side developer micro-tool built with React, TypeScript, and Tailwind CSS. It allows developers and designers to preview SVG stroke animations in real-time and export production-ready code snippets instantly.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Tech Stack](https://img.shields.io/badge/stack-React%20%7C%20TypeScript%20%7C%20Tailwind%20v4-violet)

## ✨ Key Features

- 🎨 **SVG Path Parsing:** Automatically extracts `<path>` elements and computes length metrics using native `getTotalLength()`.
- 🎛️ **Live Animation Controls:** Tweak duration, easing curves, stroke width, and colors with instant UI feedback.
- 💻 **Multi-Format Code Export:** Generate clean CSS `@keyframes` and Framer Motion JSX snippets with a single click.
- ⚡ **100% Client-Side:** Zero backend required—fast, secure, and privacy-friendly.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
